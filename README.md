# AAU 7th Semester Project — Video Object Detection Pipeline

> 🎓 Course/semester project · Computer Engineering (AI, Vision & Sound) · Aalborg University, 2022
>
> **Group:** Lukas Bisgaard Kristensen · Mate Tallosi · Tudor-Razvan Tatar

End-to-end pipeline for **video-based object detection and classification** using YOLO — from raw video annotation through frame extraction, interactive dataset curation, YOLO-format dataset generation, and IoU-based post-processing.

---

## ✨ Features

- Frame extraction from annotated videos driven by Label Studio JSON metadata
- Interactive label-review GUI for dataset curation
- Multi-variant YOLO-format dataset generation (with/without background samples, reduced variants)
- Automated train / validation / test split creation
- Post-processing with IoU-based duplicate suppression
- Visualization and statistics notebooks

## 🚀 Usage

### Quickstart

```bash
# 1. Place your video files in videos/ (not tracked by Git)

# 2. Extract annotated frames from videos
python extract_images.py

# 3. Interactively review and curate extracted labels
python data_process/data_keep_or_discard.py

# 4. Process model detection results
python post_process/run_results.py
```

## ⚙️ Configuration

### Data Layout

Video files and generated image datasets are excluded via `.gitignore`. Expected layout:

```
videos/                           ← raw .mp4 / .MP4 files (not tracked)
images/                           ← generated by extract_images.py (not tracked)
runs/                             ← YOLO training output (not tracked)
data_process/
  dsb_data_with/                  ← YOLO dataset with background samples
  dsb_data_without/               ← YOLO dataset without background
  dsb_data_with_new/              ← reduced/cleaned variant
  dsb_data_with_new_background/   ← reduced variant + extra background
```

### Detection Classes

The project uses 4 primary YOLO classes plus `OTHER`:

```
1_AND_2  ·  1_AND_3  ·  1_AND_4  ·  2_AND_4  ·  OTHER
```

Full label definitions (23 types including track-quality and directional classes) are in `label.json`.

### YOLO Config

Each dataset variant contains a `data.yaml` file (e.g. `data_process/dsb_data_with/data.yaml`) that can be passed directly to a YOLOv5/v8 training command:

```bash
# Example — adapt path and model as needed
yolo train data=data_process/dsb_data_with/data.yaml model=yolov8n.pt epochs=100
```

## ❓ FAQ

**Where are the video files?**
Video files are large and excluded from Git. Place them in a `videos/` directory at the project root before running `extract_images.py`.

**Which YOLO version is used?**
The dataset format is compatible with both YOLOv5 and YOLOv8. Training scripts are not included in this repository.

**What does each dataset variant mean?**
- `dsb_data_with` — includes background (non-object) image samples
- `dsb_data_without` — object-only samples
- `dsb_data_with_new` — reduced/cleaned version
- `dsb_data_with_new_background` — reduced version with additional background samples

**How do I run the notebooks?**
Launch Jupyter from the project root (`jupyter notebook`) and open any `.ipynb` file.
